# AlBaro (알바로)

## 소개
쉽고 빠른 대타 찾기 서비스

## 개발 기간
2024.01.06 ~ 2024.02.21

## 팀원 소개
- 구민석 - PM, Frontend
- 우연주 - Frontend
- 유승호 - Infrastructure 
- 류현웅 - Backend
- 유정현 - Backend
- 이민상 - Backend

## 주요 기능
1. 매뉴얼 관리
2. 실시간 대체인력 모집
3. 알바 쉬프트 관리
4. 알바-점주 간 채팅 기능

## 특징
1. 업무 중심의 정보 제공으로 공과 사를 분리한 아르바이트 관리 플랫폼
2. 내부 및 외부 자원 통합 관리 플랫폼
3. 점주와 알바생이 양방향으로 소통 가능한 플랫폼 (캘린더, 채팅기능)

## 핵심 기술
1. WebSocket을 활용한 실시간 채팅기능 구현
2. QR코드를 활용한 출석체크 기능 구현

### Backend
